# Design docs

RFC/ERD documents for features in this repository. Every new feature starts with one of these **before** code — see [`../AGENTS.md`](../AGENTS.md).

## How to add a doc

1. Copy [`_template.md`](./_template.md) to `docs/<NNNN>-<slug>.md` using the next number below.
2. Fill in Motivation, Diagram (Mermaid), Plan, and Verification.
3. Add a row to the index below.
